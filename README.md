# Arduino Weather Station

A simple Arduino-based Weather Station that measures temperature and humidity using a DHT11 sensor and displays the data on a 16x2 I2C LCD. The project also includes menu navigation using push buttons and visual indicators using LEDs and a buzzer.

## Components Used
- Arduino Uno
- DHT11 Sensor
- 16x2 I2C LCD
- Push Buttons
- LEDs
- Buzzer

## Features
- Real-time temperature monitoring
- Real-time humidity monitoring
- LCD menu system
- Weather condition indication
- User-friendly interface
